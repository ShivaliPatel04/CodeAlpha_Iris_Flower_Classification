# CodeAlpha Iris Flower Classification

## Project Overview

This project was completed as part of the CodeAlpha Data Science Internship.

The objective of this project is to build a machine learning classification model to classify Iris flowers into three species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Dataset

The project uses the Iris Flower Dataset.

The dataset contains four flower measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable is the flower species.

## Project Workflow

1. Imported the Iris dataset
2. Explored the dataset
3. Checked for missing values
4. Analyzed the distribution of flower species
5. Created data visualizations
6. Removed the unnecessary Id column
7. Separated features and target
8. Split the data into training and testing sets
9. Trained machine learning classification models
10. Evaluated model performance
11. Compared different models
12. Tested the model with a new flower sample

## Machine Learning Models

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest

## Results

| Model | Accuracy |
